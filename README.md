<h1 align="center">Alchemy × Convex</h1>

<p align="center">
  Deploy and manage Convex projects with Alchemy.
</p>

<p align="center">
  <a href="./packages/alchemy-convex/README.md"><strong>Read the documentation →</strong></a>
</p>

`alchemy-convex` is an [Alchemy v2](https://alchemy.run) provider
for deploying standard [Convex](https://www.convex.dev) projects from an
Alchemy stack. It manages projects, deployments, environment variables, and
authentication while the official Convex CLI handles typechecking, code
generation, bundling, and deployment.
